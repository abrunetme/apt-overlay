APT Overlay

A lightweight, declarative APT repository generator for Debian/Ubuntu. Native apt install & apt upgrade for standalone binaries and GitHub release archives.

Install a package

  • Add the repository to your APT sources.
  • Register the signing key: curl -fsSL https://apt.abrunet.me/Release.key | sudo gpg --dearmor -o /etc/apt/keyrings/abrunet-overlay.gpg
  • Install with sudo apt install sshm and update seamlessly with sudo apt upgrade.
